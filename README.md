# Womup

A modern, premium promotional advertising and landing website for WOMUP — designed to bring more value to everyday shopping through the WOMUP Shopping Coin ecosystem.

## 🚀 Features

- **100% English UI**: Clean, professional promotional copy with zero bilingual clutter.
- **Brand Identity**: Built upon WOMUP's signature color palette (Dark Navy `#05062A`, Soft Pink `#FFD0DD`, Primary Pink `#FD849F`, Purple `#6651BF`, Royal Blue `#3048C8`, Lavender `#D8C9ED`).
- **Light Theme**: Bright, modern, and inviting aesthetic with soft glowing gradients and subtle shadows.
- **Image-Rich Layout**: Curated high-resolution lifestyle photography, 3D gold Shopping Coin renders, and shopping cart visuals.
- **Visual Promotional Structure**:
  1. Sticky White Navbar with quick navigation
  2. Hero Advertisement with lifestyle visuals and key value propositions
  3. Up to ₹2,000 Monthly Shopping Benefit Promotion
  4. 3-Step "How It Works" Flow (Register Free, Shop, Get More Value)
  5. 14 Core Shopping Categories (Grocery, Medical, Restaurants, Salon, etc.)
  6. Dedicated Shopping Coin Section with 3D Gold Coin visual
  7. Visual Saving Example (₹20,000 spend → ₹2,000 benefit → ₹18,000 spend)
  8. Referral & Community Growth Concept with network flow
  9. Why WOMUP (4 Core Pillars)
  10. High-Impact Final Call to Action
  11. Comprehensive Dark Navy Footer with regulatory & compliance disclaimers
  12. Interactive Lead Enquiry / Early Registration Modal

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS 3.4**
- **Framer Motion**
- **Lucide React Icons**

## 💻 Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
